# Player-

Native Android + Android TV media player built with Kotlin, Jetpack Compose, and Media3.

## Features

- Mobile and TV-focused Compose UI
- Android TV D-pad and Media3 playback controls
- `magnet:`, `player://`, `content://`, and direct HTTP URL handling
- HTTP/HLS/DASH playback via Media3
- FebBox URL fields and secure local account configuration
- Download queue and plugin interfaces for native WebTorrent support

## Build

Open the repository in Android Studio and create a Gradle project from these files. FebBox credentials can be configured through `local.properties` and should not be committed.
